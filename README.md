# Best-Fit

Best-Fit is a prototype for an employee management application designed to simplify day-to-day tasks for both employees and managers.

### 📌 Project Overview

The project was designed based on requirements analysis and includes:

* Entity Relationship Diagram (ERD)
* Use Case Diagram
* Data Flow Diagram (DFD)
* UI/UX prototype

### 🎨 Prototype

The prototype was created using **Balsamiq** to visualize the application's interface, navigation, and key user interactions before development.

The `.bmpr` file contains the complete Balsamiq prototype.

### 🛠️ Tool

* Balsamiq
